**This text discusses on how to use the Python file (main.py) under the GitHub repository: *Inverse Estimation of Aerodynamic Parameters from Observed Projectile Trajectories - Version 1***



**Pre-requisites and usage guide:**

Refer section 2.1 of the PDF file - \[Inverse Estimation of Aerodynamic Parameters from Observed Projectile Trajectories - Version 1] under the above mentioned GitHub repository.



**Additional Tip:**

Make sure you have installed following libraries in your system - NumPy, SciPy, Matplotlib, OpenPyXL.

If not, run all of the following commands in your Terminal:

pip install numpy

pip install scipy

pip install maplotlib

pip install openpyxl
